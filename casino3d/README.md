# RFL Cruise Casino 3D

1인칭으로 걸어 다니는 RFL 크루즈 카지노 3D 플로어입니다.

## 업로드할 파일

사이트에 올릴 때는 아래 두 파일을 **같은 폴더**에 넣습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 카지노 페이지 본체 (단독 실행) |
| `people.webp` | 실사 인물 이미지. 없으면 사람이 보이지 않습니다 |

예: `rfl-cruise-tour` 사이트의 `casino3d/` 폴더에 두 파일을 넣으면 `/casino3d/` 주소로 열립니다.

## 수정할 때

- `casino.src.html` 이 원본입니다. 수정한 뒤 `python3 build.py` 를 실행하면 `index.html` 이 다시 만들어집니다.
- 게임 연결 주소는 `casino.src.html` 의 `GAME_BASE`, 선내 지도 주소는 `MAP_URL` 에 있습니다.

## 참고

- 3D 엔진(three.js)과 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- `file://` 로 직접 열면 브라우저 보안 정책 때문에 인물 이미지가 표시되지 않습니다. 웹 서버(예: Netlify)에 올려서 확인하세요.
- 모든 칩은 가상 칩이며 실제 금전 거래는 없습니다.
