# 장터 주사위 🎲

밤 장터에서 주사위 다섯 개로 족보를 맞추고, 부적으로 점수를 불려 열 번의 장날을 버티는 게임입니다.

## 여는 방법
- 이 폴더의 `index.html` 파일을 크롬 같은 웹 브라우저로 열면 바로 시작됩니다. 설치는 필요 없어요.
- 휴대폰·아이패드에서도 손가락으로 할 수 있어요.

## 하는 방법
1. 주사위 다섯 개가 저절로 굴러갑니다.
2. 남기고 싶은 주사위를 누르면 **묶입니다.**
3. **[다시 굴리기]** — 묶지 않은 주사위만 다시 굴러요 (한 판에 2번).
4. **[이걸로 내기]** — 족보에 따라 점수를 받아요.
5. 장날마다 3판 안에 목표 점수를 넘기면 엽전을 받고, **부적 장터**에서 부적을 삽니다.
6. 열 번째 장날(큰장)까지 버티면 **장터의 큰손!**

- v0.2: 따라 하며 배우기 안내, "뭘 묶을까? 추천 받기" 버튼, 쉬운 말 점수 표시(지금 내면 몇 점·목표까지 몇 점), 손그림풍 밤 장터 배경·달, 국악 5음계 배경 음악(음악·효과음 따로 끄기).
